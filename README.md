# cmsc408-sp2025-hw8

Homework 8 - World Bank Indicator Analysis - README

This project was all about analyzing data from the World Bank using SQL. The dataset included information about countries, regions, and income levels. I worked through a series of tasks that got progressively more complex.

Early tasks focused on simple things like counting rows or filtering specific countries. As the assignment went on, I had to write more advanced queries—using grouping, case statements, subqueries, and joins—to explore trends in regions and income levels. There were also parts where I had to fix data inconsistencies (like correcting the income level for a country). The earlier tasks that were only one or two steps were not too hard.

One of the bigger challenges was the multi step super long query string, at times it was hard to track the logic and find the commands needed to translate the logic from paper to SQL. 

Overall, this assignment was a good way to practice practical SQL—especially for cleaning and analyzing real-world data. It showed me how small assumptions (like which entries are actual countries) can have a big effect on the results. It also gave me a better sense of how to write queries that build on each other step by step
